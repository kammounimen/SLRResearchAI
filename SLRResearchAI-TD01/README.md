# SLRResearchAI — TD01

1. Lisez `ENONCE_TD01.md`.
2. Créez `.venv` et installez `requirements.txt`.
3. Copiez `.env.example` vers `.env`, puis choisissez Ollama ou Groq.
4. Complétez les TODO dans `slrresearch/research_questions.py`.
5. Lancez `python -m pytest -v`, puis `python main.py`.
6. Modifiez les paramètres dans `main.py` et observez-les avec Streamlit.

Ne publiez jamais `.env`.
